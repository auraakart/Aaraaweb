# aaraagate

Multi-society gated-community operating system for India.

## Product
Resident + Guard Flutter apps, Society/Super Admin web dashboards, and a secure NestJS API backed by PostgreSQL, Redis and object storage.

## Current implementation stage
Foundation / Milestones 01–03: requirements baseline, UX direction and technical architecture.

- Requirements: `docs/PRODUCT_REQUIREMENTS.md`
- Architecture: `docs/ARCHITECTURE.md`
- UX/UI: `docs/UX_DESIGN_SYSTEM.md`
