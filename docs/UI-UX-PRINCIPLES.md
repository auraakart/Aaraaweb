# Aaraagate UI/UX Principles

## Resident
- Home is an action center, not a feature directory.
- Prioritize security events and time-sensitive actions above promotional/community content.
- Use progressive disclosure so the interface stays calm despite a broad feature set.
- Visitor approval should expose visitor identity, purpose, destination and clear Approve/Deny actions.
- Use contextual status chips instead of dense tables on mobile.

## Guard
- One task per screen where practical.
- Large touch targets and high legibility.
- Camera-first capture when identity/photo is required.
- Minimize typing with unit search, recent visitors and predefined purposes.
- Explicit offline indicator and sync status.
- Language selection must not require navigating deep settings.

## Admin
- Desktop-first operational density with responsive tablet support.
- KPI cards for exceptions, not vanity metrics.
- Tables support search, filters, bulk actions and audit history.
- Destructive actions require confirmation and clear consequences.

## Visual direction
- Contemporary Indian consumer-app feel.
- Generous whitespace, restrained surfaces and clear hierarchy.
- Rounded cards and controls without excessive decoration.
- Strong semantic status states for security: pending, approved, denied, exited, flagged.
- Avoid competitor-specific colors, copy, layouts or branded motifs.
