# V5.4.10 — Partner membership console (non-production)

The existing authenticated `/partners` portal now links to a separate commercial membership console.
- Owner-only invite of an existing user by opaque UUID, owner-only role changes/revocation with confirmation, and a private invitation inbox with accept/decline.
- Reuses V5.4.9 bearer endpoints, V5.4.8 session detection, shared Admin UI, bounded runtime payload parsing, abortable reads and stale-session display suppression.
- Role assignment lists remain labels only; no user contacts, society data, financial records or gate events. Partner role is never an application/society role.
- Mutation authority, last-owner checks, invite validity and audit events remain enforced on the API, not in the browser.
- Standalone partner login, onboarding of unknown users, domain routing, multi-host session and Android distribution approval remain separate.
- No staging or main promotion. Targeted Node parser regression is part of Admin UI contracts; protected Admin validation is required before develop integration.
