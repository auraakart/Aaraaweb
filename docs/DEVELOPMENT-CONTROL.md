# Aaraagate Development Control

This branch is the active development baseline for Aaraagate. Changes must remain aligned with the requirements traceability document and be implemented as complete vertical slices.

## Current priority
Complete Visitor Management end-to-end: resident visitor request, approval/rejection, pass issuance, gate verification, check-in/check-out, and audit coverage.

## Branch policy
- `develop` is the active integration branch.
- `main` remains the stable release branch.
- Do not overwrite unrelated existing work.
- Production readiness requires UI states, validation, authorization, audit review, tests, and acceptance criteria.
