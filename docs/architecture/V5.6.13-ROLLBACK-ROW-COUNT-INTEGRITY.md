# V5.6.13 — Fail closed on partial migration rollback evidence writes

**Baseline:** `develop` `dd979dd711390b5a246ca614c8e458ba5c53d0bf` (V5.6.12 merged).

## Root cause

Opening-balance migration rollback already validates every journal-bound row under the migration batch lock and performs journal reversal, row updates and the migration batch status transition in one PostgreSQL transaction. However, its `UPDATE MigrationBatchRow SET rolledBackAt...` previously discarded PostgreSQL's affected-row count. If the row set changed between evidence read and UPDATE, a smaller set of rows could be marked rolled back while the batch was marked ROLLED_BACK.

## Targeted fix

Require the count returned by the actual `MigrationBatchRow` rollback UPDATE to equal `MigrationBatch.totalRows`. On mismatch throw an existing-style `ConflictException` *before* the `MigrationBatch` status transition. Because the journal reversal and row writes are in the same transaction (V5.6.7), the failure rolls back all financial effects as well. No changes to correctly evidenced rollbacks, controller routes, permissions, schemas, migrations, CI workflows, or cross-society boundaries.

## Regression evidence

- Unit test: a fully valid two-row batch and POSTED journal can reverse, but a simulated single-row database update produces the new conflict before the final batch-state UPDATE.
- Disposable PostgreSQL test: execute the **actual** journal reversal and row rollback UPDATE within one real transaction, intercept only the reported row count as 1 instead of 2, verify the rollback rejects, the original journal is still POSTED, no reversal journal exists, no evidence rows were marked, and the migration batch stays COMMITTED. Existing real-DB recovery test then performs the successful rollback and confirms idempotency.
- The real-DB suite runs only in GitHub Actions against `localhost:5432/aaraagate_ci` disposable PostgreSQL and must never be run against shared or live financial data. Existing full API CI provides the suite; do not create an additional CI job.
