## Engineering change

`packages/config/src/android-test-oci-layout.mjs` reuses the pinned Ed25519 DSSE TEST-image claim verifier from V5.5.36 and checks a **real on-disk** OCI v1 layout, not an unverified caller-supplied hash report. The exact `index.json` must select one Linux/amd64 or Linux/arm64 image manifest whose SHA-256 digest equals the signed operator-pinned image digest. The manifest's size and bytes are checked, then every referenced config and compressed layer blob is streamed from `blobs/sha256` and checked for digest and length. The config's source-revision label and architecture must equal the signed source SHA and explicitly reviewed platform. This narrowly supports a single OCI manifest with 1–8 gzip layer descriptors; no multi-platform index resolution or unpacking.

The verifier rejects symlinked roots and blob paths, noncanonical layout directories, additional or missing blobs, unexpected media types, unsafe file types/hardlinks, invalid descriptors, excessive file sizes or layout complexity, signed-image digest drift, foreign source/platform, and files modified during streaming. It reads files only. No registry access, image pull, Docker or Flutter commands, credentials, tar extraction or network calls are performed.

`scripts/android-test-oci-layout.test.mjs` generates small disposable OCI fixture files, ephemeral attestor/worker keys, signed DSSE envelopes and positive/negative tests. The existing Repository structure job automatically invokes the lightweight `scripts/check-v4.79.1.9-v5-oci-layout.mjs`. Protected API/Admin/Flutter gates remain authoritative; no CI workflow edits or Android rebuild.

## Trust and release boundary

This checks **local OCI layout bytes only**, and the signed claim is from ephemeral CI fixture keys. It cannot establish whether the independently authenticated runtime actually loaded those bytes, whether a remote registry serves the same manifest, or whether a remote operator controls its attestor/worker keys. Its result retains `registryDigestVerified:false`, `runtimeImageAttested:false`, `imageRunningOnAuthenticatedWorker:false`, `runtimeTransportAuthenticated:false`, `immutableMountVerified:false`, `singleUseChallengeConsumed:false`, `buildExecutionAuthorized:false`, `artifactProduced:false`, `dispatchAllowed:false`.
