## Reuse, not replacement

V5.5.19 already verifies Linux `status` capability/security flags and four strictly pinned read-only SDK mountpoints for `/proc/self`. V5.5.39 signs process claims, V5.5.40 verifies a read-only nonce-bound mTLS wrapper in disposable fixtures, and V5.5.41 records a hashed probe nonce once. V5.5.42 adds `packages/config/src/android-test-linux-observer.mjs` with a **different-process** host-side read of `/proc/<pid>/stat`, `/proc/<pid>/ns/mnt`, `/proc/<pid>/status` and `/proc/<pid>/mountinfo`. It uses only fixed Linux `/proc` paths and bounded read-only operations; no shell, child execution, API endpoint or partner-supplied path. A double sample of stat starttime ticks and mount namespace symlink around the security reads rejects apparent PID reuse or namespace swapping. Reuses V5.5.19 `evaluateTestAndroidLinuxIsolationSnapshot` to fail closed on root/capabilities, missing `no_new_privs`/seccomp or pinned read-only SDK mounts. The pinned local inspection policy must be provisioned by a trusted operator, not supplied by the worker or partner. The parser has fixture tests plus a live `/proc` sanity check that rejects normal CI as an approved isolated runner.

## Hard trust boundary

Locally observed kernel process identity and SDK mount flags **do not reveal the OCI image digest**, which must be validated through an **independently provisioned runtime/operator source** (e.g. authenticated container runtime state and registry/layer digests). A same-host observer is not automatically independent of the worker, and a process may change after the sampled window. A synthetic snapshot never establishes a kernel fact: the pure evaluator returns `measuredKernelProcessSnapshot:false`, whereas the live reader may report only **host-local** `measuredKernelProcessSnapshot:true`. Both retain `independentHostOperatorVerified:false`, `independentOciImageDigestVerified:false`, `runtimeImageAttested:false`, `immutableMountVerified:false`, `singleUseChallengeConsumed:false`, `buildExecutionAuthorized:false`, `artifactProduced:false`, `dispatchAllowed:false`.
