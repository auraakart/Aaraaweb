# V5.5.21 — Disposable pinned Flutter wrapper input assembly

V5.5.20 (PR #1311) merged into develop at `2dd8903b9c617d3db53eba274eeb4cc1bfea5c9a` after protected CI run 38598412753 passed.

`materializeVerifiedTestAndroidWrapperInputs` is a TEST-only, nonexecuting assembly stage. It requires the V5.5.20 independently verified final Android 12 overlay, durable accepted signed TEST worker evidence and V5.5.16 complete nativeTemplate byte-tree receipt from independently controlled Flutter 3.47 policy. It scans every generated Flutter native template byte using the *same domain-separated V5.5.16 SHA-256 tree canonicalization*, detects links, devices, writable files and mutated/missing/extra paths, checks the single default Resident/Guard Kotlin launcher, then copies only verified original paths and overlays ten approved native files into a fresh private temp root. The default generated MainActivity.kt is intentionally removed to prevent two launchers. No pre-existing native/template source is modified. The resulting immutable metadata receipt binds worker/run, manifest, source, lock, reserved versionCode, min/target/compile SDK API 24/36, approved native overlay digest, pinned template digest and every final file SHA-256.

**Important boundary:** tests create a *synthetic test template* and run without actual Flutter. An independently deployed, authenticated runner still must use Flutter 3.47 to generate a genuine Android wrapper, attest the running OCI image, ensure immutable SDK mounts, verify the expected native-template digest, perform a further final assembled tree check, obtain a fresh single-use server build authorization and independently verify APK/AAB package identity, signer, ABIs, ZIP archive SHA and installation isolation. This stage deliberately reports `flutterWrapperGenerated:false` (cannot prove upstream template origin itself), `runnerImageAttested:false`, `dispatchAllowed:false`, `executionStarted:false`, `artifactProduced:false`, and `signerVerified:false`. No new route, secrets, productionization or release-branch changes.
