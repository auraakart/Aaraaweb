## Implementation and cryptographic boundary

`packages/config/src/android-test-oci-runtime-transport.mjs` makes a **real TLS 1.3, client-certificate-authenticated POST** only to fixed canonical `/v1/test-runner/runtime-evidence` with independently operator-pinned CA, server hostname and SPKI and pre-pinned client SPKI. Sends bounded JSON identity and a fresh 256-bit transport nonce; does not submit source or execute a build. The server response must echo that nonce and have an independent observer Ed25519 signature over the response wrapper (separate protocol domain), including the V5.5.39 double-signed worker+observer DSSE runtime claim. The V5.5.36 image claim and worker/run/source/challenge/container/mount namespace/transport SPKI must match operator-controlled policy.

The repo already has the **V5.5.14–15 durable issuance/single-use signed acceptance** in PostgreSQL. This slice neither replaces that service nor consumes a new runtime challenge. Existing V5.5.18 mTLS identity-only route remains separate. The new route is an additional **non-dispatchable runtime-claim challenge contract**, not an execution route. Strict response type, size, signed payload allowlist, redirect refusal, and wrong nonce/signature/certificate/mount claim rejection are tested with a disposable locally authenticated TLS fixture.

## Explicit limits

Two signed claims plus successful local mTLS do **not** prove that a real separately operated worker is running the claimed OCI image, that the observer actually inspected a kernel process/namespace or immutable mounts, or that independent organizational key custody was established. The fresh transport nonce is checked cryptographically but is **not** durably consumed. The server-side fixture is not an externally provisioned runner, and application-level client certificate authentication remains a server configuration responsibility. This preflight reports `independentlyProvisionedWorkerVerified:false`, `remoteProcessMeasured:false`, `runtimeImageAttested:false`, `immutableMountVerified:false`, `singleUseChallengeConsumed:false`, `buildExecutionAuthorized:false`, `artifactProduced:false`, `dispatchAllowed:false`.
