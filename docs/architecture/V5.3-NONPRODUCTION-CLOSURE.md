## Rollback and next boundary

Revert cosmetic client usage to the built-in default brand if runtime presentation cannot be trusted; retain additive database schemas and immutable society brand revision history. Auth, society ownership, finance/legal issuer, gate and SOS remain distinct from appearance. No stale image bytes are shared across session/society changes. V5.4 begins partner-licensing/domain **contracts only** without activating partner entitlements or access; V5.5 packaged distributions and V5.6 end-to-end closure remain separately gated. Staging/main unchanged.
