## Reused and added checks

The existing V5.5.42 host-local /proc PID/mount isolation and V5.5.43 target rootfs/cgroup v2 checks are reused unchanged. This slice adds a read-only V5.5.44 executable-identity check that double-samples target Linux PID stat/starttime and mount, PID and user namespace symlinks. It opens **only** `/proc/<pid>/exe` to hash bounded executable bytes via an open file descriptor, confirming inode, size and timestamp stability across the read; it also hashes bounded binary `/proc/<pid>/cmdline` bytes, and requires the kernel executable symlink and hashes to match separately pinned operator policy. No user path is executed or opened, no OCI socket is accessed, and no remote service is claimed. Fixture negative tests reject PID reuse, namespace swap, binary/argument substitutions, invalid bounds and permission injection. An ordinary live CI process must fail the protected worker precondition.

## Non-attestation boundary

Local observed executable hash is **not** proof of the running OCI image digest, registry layers, independent host control, executable immutability across the process lifetime or secure external operator key custody. The pure parser outputs `measuredKernelExecutable:false`; a live local read may set that one field true only after prior isolated cgroup/rootfs checks. All outputs remain `independentObserverVerified:false`, `independentOciImageDigestVerified:false`, `runtimeImageAttested:false`, `immutableMountVerified:false`, `singleUseChallengeConsumed:false`, `buildExecutionAuthorized:false`, `artifactProduced:false`, `dispatchAllowed:false`.
