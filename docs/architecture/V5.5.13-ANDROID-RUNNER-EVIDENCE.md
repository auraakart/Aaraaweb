# V5.5.13 — Cryptographically bound TEST runner evidence (not executable dispatch)

Baseline: V5.5.12 PR #1303 merged to develop at 40186f322e624d7b4430de5ae02bf417d9d3235b after all protected CI checks passed.

This slice verifies domain-separated Ed25519 signatures over a strictly shaped TEST worker assertion. It binds a single V5.5.8 CONSUMED_TEST_NO_EXECUTION record to its version reservation, reviewed distribution and manifest, immutable source/lock, the V5.5.11 verified four-file native patch digest inventory, and the V5.5.12 verified executable toolchain digest inventory. The statement is additionally bound to a short-lived server-expected run ID, nonce, worker ID and pinned OCI runner image SHA-256 claim. The worker public key is accepted only from an independently managed server-side trust policy, not from the attestation or a partner request. TTL is limited to 90 seconds; signatures are canonical base64url with an Ed25519 key and a dedicated domain prefix. Resident/Guard positive cases and cross-society/worker/image/version/source/replay/tamper rejection cases run in the existing required Node contract suite.

Security: Signature validation demonstrates possession of an allowed signing key and integrity of the claimed bindings. It **does not** establish that the OCI image actually ran, authenticate a network channel, provision/secure the worker private key, verify the full SDK/template tree or prevent replay by itself. A durable server-side one-time nonce/run ledger, identity-bound worker transport, immutable image attestations and atomic consumption must follow before any real build execution. The verifier returns serverReplayBarrierVerified:false, runnerTransportAuthenticated:false, runtimeImageAttested:false, dispatchAllowed:false, and artifactProduced:false. No production credentials or network worker endpoint are introduced.

No Android generation, Gradle/Flutter invocation, signing, APK/AAB artifacts, API/DB migration, default demo pipeline change or staging/main modification in this slice.

Validation: node --test scripts/android-build-contract.test.mjs plus required protected GitHub CI. Next: persist one-time worker/run replay guard, tie a real isolated authenticated runner to the claim, attest immutable build image and complete Flutter/Android SDK/template pins, then proceed with TEST wrapper generation, splash theme integration and bounded signed APK/AAB.
