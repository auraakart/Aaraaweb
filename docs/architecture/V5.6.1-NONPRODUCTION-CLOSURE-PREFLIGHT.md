## Why this slice

Repeated “no progress” reports obscured three different states: (1) transient GitHub workflow syntax and Build Tools signing-report mismatch, which have been fixed, (2) green scoped engineering CI, and (3) missing independently established external acceptance. A green build must never imply V5 is ready for partner distribution or main promotion.

The lightweight regression guard `scripts/check-v4.79.1.4-v5-closure-preflight.mjs` is automatically run by the **existing** V4.79 invariant discovery in protected Repository structure. It reads the actual versioned release manifest, requires a nonproduction program and manual main approval, rejects duplicate/missing milestone entries, recognizes the three already-validated base Android slices, and lists unfinished milestones plus independently unverified acceptance. Its adversarial fixtures ensure forged completion, productionization and auto-main changes cannot authorize release. **No CI YAML edited** and no Android rebuild is requested.
