# V5.5.33 — Genuine base Android TEST AAB smoke

Prior V5.5.32 PR #1323 passed both genuine base APK build and v2 signing checks (run 38641846894).
This slice runs Flutter 3.47 debug appbundle builds after those APK jobs in the same two scoped, ephemeral CI matrix entries.
An AAB is ZIP/JAR signed, not APK v2 signed. The TEST script checks ZIP integrity, BundleConfig.pb,
base manifest, DEX and arm64 engine membership. JDK jarsigner verifies the cryptographic signature,
keytool prints the local signer certificate, and the strict existing TEST JAR-parser rejects unsigned critical
entries, invalid certificates and ambiguous signers. SHA-256, byte count, source commit and ephemeral reports
are retained for 1 day. Android smoke is required by protected merge gates when its files change.

LIMITATIONS: The certificate fingerprint is observed locally rather than checked against independently
trusted release policy. These are BASE debug AABs, not partner-specific approved binaries. No real partner
signing authority, independent OCI runner attestation, TEST dispatcher, device test, productionization,
staging/main promotion, or store publication. Do not mark this slice accepted until both real CI matrix
jobs pass and hashes are recorded.
