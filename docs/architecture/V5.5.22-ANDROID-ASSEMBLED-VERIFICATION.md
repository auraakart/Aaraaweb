# V5.5.22 — Independently verify assembled TEST Flutter native tree

Baseline: V5.5.21 native assembly merged into `develop` as `2e64226c35d1c63c12aab6a0d634c03c6a228667`, protected CI run 38599846431 successful.

This slice provides a separate **non-executing, fail-closed post-assembly verifier**. It independently rescans the complete temporary Android wrapper input directory from disk, rejecting all unexpected or missing paths, symbolic links, hardlinks, devices, writable directories/files and excess size or file count. It rechecks the upstream Flutter 3.47 generated template against the independently pinned full-tree V5.5.16 digest, and recomputes the approved V5.5.20 Android 12 TEST overlay before deriving the exact expected output from both inputs. The old default Kotlin launcher must not survive assembly, and all ten replaced native file paths must originate in the reviewed overlay. Each surviving template file must retain exact SHA-256, byte count and provenance. The separate metadata receipt binds app role/application ID, worker/run, manifest/source/lock, immutable version reservation, minSdk 24, target/compileSdk 36, expected input hashes, and the final canonical assembled digest.

**Security boundary:** A pre-flight check over mutable local files alone does not attest a real independently provisioned OCI worker, nor keep a tree immutable during subsequent execution. The function never launches Flutter/Gradle or authorizes execution and returns `runtimeImageAttested:false`, `immutableMountVerified:false`, `buildExecutionAuthorized:false`, `artifactProduced:false`, `dispatchAllowed:false`. Tests use a synthetic Flutter-native template, not a genuinely generated wrapper. Real runner provisioning, authenticated independent runtime-image attestation, one-use server execution authority, actual APK/AAB building, signer/package/ABI/hash verification and device validation remain pending. Staging and main branches are excluded.
