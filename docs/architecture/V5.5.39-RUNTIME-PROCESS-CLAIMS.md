# V5.5.39 — Independent TEST worker/observer signed runtime image/process claim preflight

Baseline: `develop` `d798cfac912bd45dc3ef159bcffefa81e722eb9b`. V5.5.38 runtime PR #1342 and evidence PR #1343 are merged with required protected CI.

## Scope

Add `verifyPinnedTestOciRuntimeClaim` in `packages/config/src/android-test-oci-runtime-claim.mjs`. Revalidate the existing operator-pinned V5.5.36 signed OCI image claim; require a second DSSE envelope whose canonical JSON payload is signed by **two separately pinned Ed25519 keys**: a worker key and an independent runtime observer key (both distinct from the image attestor). Bind to exact image SHA, source SHA, worker/run ID, operator nonce, manifest digest, acceptance/challenge IDs, container ID, mount namespace ID, immutable mount assertions and pinned transport server SPKI. Enforce strict TEST identity, payload key allowlists, key ordering, canonical encoding and short UTC validity. No secrets in the repository.

Check a small positive and negative signature/scope matrix via `scripts/android-test-oci-runtime-claim.test.mjs`, automatically invoked by Repository structure through `scripts/check-v4.79.1.11-v5-runtime-claim.mjs`. No `.github/workflows` edit or Android job.

## Critical trust distinction

**A correctly signed claim is not an independently verified measurement.** Even with worker/observer cryptographic separation, the fixture does **not** inspect a live remote container, process or namespace, verify actual mount flags or registry image bytes at that worker, prove distinct real-world key custody, authenticate a network peer, or atomically consume a persisted challenge. The supplied mount and process data remain **self-reported assertions** signed by fixture keys. This preflight neither accepts V5.5.18 or V5.5.38 receipts as remote authority nor attempts to turn prior booleans into permissions.

All authority flags remain false: `runtimeImageAttested`, `registryDigestVerified`, `imageRunningOnAuthenticatedWorker`, `remoteProcessMeasured`, `immutableMountVerified`, `runtimeTransportAuthenticated`, `singleUseChallengeConsumed`, `buildExecutionAuthorized`, `artifactProduced`, `dispatchAllowed`.
