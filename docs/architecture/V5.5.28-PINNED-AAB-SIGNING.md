# V5.5.28 — TEST AAB signing-report verification with pinned JDK tools

Baseline: V5.5.27 PR #1318 merged into `develop` as `0eaf387a4bbe4b878068976a774317c33ec69130`; required CI run 38617239816 passed.

An AAB uses JAR signature verification, not APK Signature Scheme v2. This code-only, read-only adapter complements V5.5.27 bundletool manifest validation with fixed `jarsigner -verify -verbose -certs <artifact>` and `keytool -printcert -jarfile <artifact>` commands. Both JDK executables must have an independently supplied exact SHA-256 pin, canonical nonlinked paths, safe permissions, and single links. The TEST AAB archive, both executables and previous bundletool identity receipt are checked before execution; file hashes are rechecked after each command. No shell or signing/write arguments are accepted. The parser requires jarsigner's verified report, signed critical module entries, exactly one signer and the immutable approved SHA-256 fingerprint of its leaf certificate.

**Boundary:** Verification of text emitted by local pinned tools is not independent container/runtime attestation; do not treat fake output as a cryptographic signing proof. `independentlyAttestedRunner:false`, `actualSignerVerifiedByTrustedAttestedRunner:false`, `artifactApproved:false`, `buildExecutionAuthorized:false` and `dispatchAllowed:false` remain explicit. All regression fixtures use a synthetic ZIP archive and fake JDK executables; no Android binary was built, signed or installed. A real isolated runner with independently attested toolchain and fresh server-side completion authority remains required.

No productionization, cloud, secrets, publish, staging or main changes.

Locally pinned TEST certificates may be self-signed. A `jarsigner` verified result with signer errors is accepted only for the specifically recognized self-signed/PKIX trust-chain diagnostics plus an exact independently approved leaf fingerprint; unexpected errors, expiry, unsigned entries and signer ambiguity remain rejected. This is still local reported evidence, not trusted-runner attestation.
