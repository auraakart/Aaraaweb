## What this slice measures

Adds `evaluatePinnedTestLinuxCgroupRootSnapshot` and `inspectLocalTestLinuxRunnerCgroupRoot` in `packages/config/src/android-test-linux-cgroup-observer.mjs`.

A separately configured host observer can take **read-only** bounded reads of the target PID's Linux `/proc/<pid>/stat`, `/proc/<pid>/ns/mnt`, `/proc/<pid>/cgroup` and `/proc/<pid>/mountinfo`. The live reader reuses **V5.5.42** target-process SDK isolation and stable identity checks, then samples PID starttime and mount namespace before and after its own cgroup/root reads. This rejects obvious PID reuse or namespace substitution during observation, but not later races.

The operator-pinned policy requires an exact cgroup v2 path explicitly containing the unique 64-hex container ID, exactly one matching cgroup record, and exactly one root mount record with exact root, filesystem and source plus `ro,nosuid,nodev` and read-only superblock flags. It refuses v1/hybrid hierarchies, root path traversal, writable/superblock roots, extra policy fields, invalid image SHA and mismatched process identity. Unit tests use synthetic kernel snapshots; the live CI sanity probe rejects its ordinary process as a protected TEST worker. The approved SDK mount state remains V5.5.42's responsibility.

## Security boundary and dependency

**This is host-local kernel observation, not independent OCI image attestation.** Matching cgroup path to a pre-pinned container ID does not prove the image digest, source code, immutable lifetime or independently operated observer. The snapshot parser cannot attest a real kernel; only a live observer can report local reads. All outputs always retain `independentlyProvisionedObserverVerified:false`, `independentlyVerifiedOciImageDigest:false`, `runtimeImageAttested:false`, `immutableMountVerified:false`, `singleUseChallengeConsumed:false`, `buildExecutionAuthorized:false`, `artifactProduced:false`, `dispatchAllowed:false`.

Next actual external dependency: provision a remotely authenticated, separately operated TEST observer and OCI runtime/registry state source; bind actual observed PID/namespace/cgroup/container ID to exact OCI manifest/config/layer bytes and challenge/worker identity. The V5.5.41 persistent read-only probe ledger does not grant a build-execution challenge. APK/AAB signing and Partner A/B co-installation remain blocked. No workflow, secrets, staging or main modifications.
