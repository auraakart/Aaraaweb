# V5.5.14 — Durable single-use TEST runner challenge issuance

Baseline: V5.5.13 PR #1304 merged to develop at e245c1e4c7b0a8183d24061a59ebb42b11c3e4c3 after green protected CI.

This slice introduces an internal, default-disabled server-side challenge issuer that uses the existing live TEST distribution/reservation checkpoint and active allocation transaction. An independently configured TEST worker ID and runner OCI image SHA-256 reference are required. The server generates a cryptographically random 256-bit nonce and independent run ID and stores only the nonce SHA-256. PostgreSQL enforces one challenge per previously consumed worker claim, globally unique run ID/nonce digest, 60-second expiry, FK relationships, append-only evidence and trigger-level current allocation/approval/revision and actor/worker/version checks. An exact run ID, nonce and policy image claim can be carried into the V5.5.13 Ed25519 signature verifier. The raw nonce is returned only to its internal caller: **do not expose this method through public HTTP**.

This is a durable **challenge issuance** boundary, not yet durable acceptance of a signed worker response. The next slice must atomically validate and consume the signed proof against this challenge exactly once, with authenticated runner transport and an independently pinned public key. The image digest is a policy reference, not actual evidence the image executed. No external build worker, session API, Flutter/Gradle process, APK/AAB or signature/archive verification is provided here. All outputs remain TEST-only and dispatchAllowed:false.

Validation: Prisma validate/generate, API typecheck/unit tests, required protected CI, and native PostgreSQL constraints/immutability under CI. No staging/main promotion, default demo changes, live DNS or productionization.

Next: atomically consume signed response against the issued run/nonce once, bind authenticated worker transport, attest immutable image and full SDK/template tree, then progress to isolated TEST Android wrapper generation and bounded APK/AAB.
