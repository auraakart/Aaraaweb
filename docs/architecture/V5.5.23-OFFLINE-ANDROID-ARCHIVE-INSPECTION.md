# V5.5.23 — Offline bounded Android TEST archive inspection

Baseline: V5.5.22 PR #1313 merged to develop at `af03b45764652adc55f500c7f4880900114a66e3`; protected CI run 38602382985 green.

This is **code-only, no productionization**. The TEST archive inspector accepts an already-existing artifact candidate from a trusted local workspace, refuses non-TEST plan/reservation inputs, demands the exact derived TEST Resident/Guard output basename, a canonical nonlinked regular file, no hardlinks or group/world write permissions, bounded file size, and stable file identity during reading. It independently parses ZIP32 local and central headers; rejects multi-disk/ZIP64, comments, encryption, unsupported compression, traversal, duplicate files, unsafe data sizes/compression ratios, contradictory entry headers, overlapping local records, missing Android APK/AAB required structural paths and CRC mismatches. It inflates bounded DEFLATE entries, checks all member CRC32 values and computes complete archive SHA-256. TEST fixtures and mutation attacks verify the contract; the inspector does not rely on an external ZIP parser.

**Important:** This reports `centralDirectoryVerified:true`, `allMemberCrcsVerified:true` but deliberately **`archiveVerified:false`, `signerVerified:false`, `androidPackageVersionVerified:false`, `artifactApproved:false` and `dispatchAllowed:false`**. ZIP structure cannot validate binary Android manifest package/version/ABIs, APK Signature Scheme v2/v3/v4, TEST signer certificate fingerprints or an AAB's bundletool signature. A trusted external `aapt2`, `apksigner` and `bundletool` verification stage must independently examine real test outputs and issue a server-bound completion proof after fresh commercial/revision authorization. The test fixtures are synthetic ZIP archives and **no real APK is produced**. This is not productionization, does not change staging/main and adds no public API endpoint.
