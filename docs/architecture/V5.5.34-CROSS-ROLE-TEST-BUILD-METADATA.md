Both real base Resident and Guard debug APK/AAB builds, archive and signing inspections completed successfully.
This slice runs a fail-closed consistency check across small, detached JSON metadata receipts from the
two independently executing TEST Android matrix jobs. The receipts re-validate role-specific APK and AAB
SHA-256s, exact source SHA, default app package IDs, SDK 24/36, the locally observed same-role debug
signer fingerprint, and explicit non-authority flags. The comparison rejects a Resident/Guard package
collision, artifact collision, mismatched source commit or unauthorized release flags.

Each matrix job publishes only one small JSON metadata file as a seven-day artifact; the follow-up job
downloads only these (not the large binaries), checks both, and is part of the reusable Android TEST
workflow that protected CI already requires for relevant code changes. Focused Node regression tests
cover swapped roles, source changes, SDK mismatch, signing mismatch and authority leakage.

**Non-authority boundary:** This does NOT test Android device/emulator co-installation, Partner A/B
branded distribution IDs, independently attested OCI builders, production signing or approval.
The debug signer certificate is observed locally, not independently pinned against release policy.
No staging/main promotion or productionization.
