Status: Repository-only evidence re-score after V4.15 Governance Operations & Committee Workflow Depth closure

This scorecard uses the V4 program's own categories and counts only implemented, tested repository capability. It is **not** an independent market survey, customer benchmark, legal certification or production-hosting certification.

**Overall repository evidence score: 9.04 / 10.**

The overall score is the simple arithmetic mean of the eight V4 program categories above: (9.3 + 9.3 + 9.0 + 9.1 + 9.1 + 9.1 + 9.4 + 8.0) / 8 = 9.0375, reported as 9.04. The V4.15 increase is intentionally limited to Administration/governance because that is the dimension with materially new repository capability: operator ergonomics, readiness/closure evidence and auditable action follow-through. The increase remains conservative because real committee usability, society-specific bye-law acceptance and legal/statutory validity are external evidence.

## Important boundary

The 9.04 score reflects repository implementation and automated evidence only. Production/field readiness remains exactly 8.0. V4.15 does not prove real committee usability acceptance, society-specific bye-law/legal validity, hosted production behavior or field governance outcomes. Those require external evidence and remain outside this repository-only score.
